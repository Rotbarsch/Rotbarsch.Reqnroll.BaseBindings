# Rotbarsch.Reqnroll.Demo

A collection of demo features demonstrating the capabilities of the Rotbarsch.Reqnroll library.

## Changing the port
If you need to change the port that the DemoWebApi service listens on, update the base URL in `Rotbarsch.Reqnroll.Demo/Rotbarsch.ReqnrollSettings.Development.json`, specifically the `demoApiBaseUrl` variable under `globalVariables`.
